Finger Cursor

Your cursor is now a telescopic finger pointer. It's a real 3D model (three.js) casting a real shadow onto the page. Click and the tip drops onto the glass with a hard plastic tick.

Taps: 0

Use it

<script type="module" src="finger-cursor.js" data-auto></script>

<!-- or -->
<script type="module">
  import FingerCursor from './finger-cursor.js';
  const cursor = await FingerCursor.init({ hand: 'peace', color: '#ffb3c7' });
</script>
